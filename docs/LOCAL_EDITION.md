# 观己 Hygieia 本地版

这是独立运行的本地试用版，数据保存在自己的电脑。无需 Node.js、npm、数据库账号或 ChatGPT 登录。包内包含经过官方 SHA-256 清单校验的 Node.js 运行环境及许可证。

## 下载与启动

在 GitHub Releases 中选择与你的系统一致的 **Hygieia 压缩包**，不要选择 GitHub 自动生成的 Source code。下载后完整解压，再启动：

- Mac Intel：选择 `darwin-x64.zip`；Apple 芯片：选择 `darwin-arm64.zip`。解压后双击 `启动观己.command`。
- Windows 64 位：选择 `win-x64.zip`，解压后双击 `Start-Hygieia.cmd`，不要直接在压缩包内运行。
- Linux 包仅供熟悉本机权限的使用者；运行解压目录的 `Start-Hygieia.sh`，桌面文件管理器是否支持双击执行取决于系统设置。

浏览器会自动打开。首次使用是空白个人空间，数据库自动创建。Mac 构建会验证运行文件的签名，必要时添加本地临时签名；这不等同于开发者签名或 Apple 公证，系统可能阻止首次运行。请核对下载来源和校验文件，按照系统提示决定是否允许打开。当前不是已公证的 `.app` 或安装向导。

启动后保留终端窗口。重复双击会重新打开已有实例，不会启动第二份数据库服务。退出时在「偏好设置 → 本地版」点击「退出本地服务」，确认记录已保存后关闭页面。直接退出启动窗口可能留下浏览器待写入副本，下次启动后可以继续同步。

## 第一次使用

全新个人空间首次打开时，会出现两步引导：了解本地保存方式、设置称呼与常用模块，再选择创建第一个任务、导入体脂秤报告或恢复已有 JSON 备份。也可以先进入总览或选择「稍后设置」。选择模块只影响常用入口，其他模块依然可用；不会创建虚构记录。

已有记录的升级用户不强制弹出引导。在首页或「偏好设置 → 本地版」可随时重新打开。完成或跳过的状态、常用模块保存在本地数据库，重启程序或更新版本后继续保留；它们属于本机使用偏好，不包含在个人记录 JSON 备份中。

报告入口打开核对表单，原图只在浏览器识别；恢复入口让你选择备份，并在写入前预览范围。不要把体脂秤截图当作观己 JSON 备份导入。

右上角「?」提供使用帮助、问题反馈与功能建议。反馈会打开 GitHub 的填写页面，需要你核对、补充并自行提交；仅预填软件版本和系统类型，不附带本机日志、数据目录、健康报告或备份。不要在公开反馈中粘贴私人记录。

## 数据在哪里

- macOS：用户目录中的 `Library/Application Support/Hygieia`。
- Windows：`%LOCALAPPDATA%\Hygieia`。
- Linux：`$XDG_DATA_HOME/Hygieia`，没有设置时使用用户目录中的 `.local/share/Hygieia`。

设置页可以打开数据目录。`hygieia.sqlite` 是主数据库，`profile.json` 是本机个人空间标识；两者都要保留。`running.json` 是当前进程的临时授权信息，不要分享。浏览器另有未提交内容和缓存。

更新时退出旧程序，解压新版并启动即可，数据目录不在程序目录内。不要删除数据目录或 `profile.json`。更新前应先导出完整备份。迁移按序执行并校验已应用脚本，不会通过重新建库来跳过错误。

日常备份请用设置页的「下载完整备份」，保存到另一位置。后台恢复点仅在本地程序运行且启用备份时执行，保存在同一个数据库中，不能代替独立备份。关闭程序后复制数据目录可用于同机恢复；迁移到另一电脑优先导出、导入完整 JSON 备份。数据库和备份没有端到端加密，电脑本身的账号权限和磁盘保护仍然重要。

## 第一版的边界

- 核心记录、任务、资产、自媒体、手记、复盘和浏览器本地报告识别可使用；首次打开没有作者数据或演示记录。
- **不会上传到作者网站，不会自动跨设备同步。** 原网站与本地版是两个独立数据空间。
- Apple 健康 / PulsHealth 自动连接尚未完成本地适配；当前使用手动健康记录、报告导入或已有观己 JSON 备份。云端连接配置不能直接用于本地版。
- 任务提醒仅保存计划，尚未接入微信等通知渠道。
- 本机同一操作系统账户使用一个个人空间；不是可注册的多用户在线平台。
- 只监听 `127.0.0.1:8797`，不要映射到公网或局域网；手机不能通过此地址访问电脑。
- 关闭互联网仍可记录和 OCR 识别；OCR 模型在包内，识别结果需要人工核对。

如果端口被其他程序占用，启动窗口会提示并停止，不会结束其他程序、切换数据目录或清空数据库。若重复打开没有进入授权页面，重新运行启动文件，不需要登录云端账号。

## 开发者

Node.js 22.13+，无需安装 npm 依赖：

```sh
node scripts/build-local.mjs
node --test desktop/local.test.mjs desktop/onboarding.test.mjs
node dist/local/server.mjs
```

测试启动临时回环服务，使用合成数据并清理临时目录。单独测试目录可以使用 `node dist/local/server.mjs --data-dir <绝对目录> --port 8798 --no-open`。修改端口会改变浏览器缓存所属的源地址，日常使用应保持默认端口。

打包需要 Python 3，并需要联网从 Node.js 官方下载运行环境：

```sh
python3 scripts/package-local.py
```

打包脚本只包含 `dist/local` 与经过校验的运行环境，不复制源码工作区、健康数据库、浏览器缓存或原站点配置。生成文件在忽略的 `releases/` 中。包内 `FILES-SHA256.json` 与压缩包旁的 `.sha256` 可用于完整性核对；它们不代替代码签名。
