首个无需配置开发环境的本地试用版。

- 完整解压后双击启动，内置官方校验的 Node.js，无需安装 npm 或登录 ChatGPT。
- 自动创建 SQLite 数据库，使用已有数据验证、冲突保护与备份逻辑。
- 数据保存在自己的电脑，浏览器内置 OCR 离线可用。
- 提供重复启动处理、本机授权与设置页安全退出。

请选择系统对应的 Hygieia ZIP（Mac Intel / Apple 芯片或 Windows x64），不要下载 Source code 作为启动包。Mac 包目前未公证签名，第一次运行可能需要系统确认。

本版本不会自动跨设备同步。Apple 健康 / PulsHealth 自动连接尚未适配本地版；可先使用手动录入、体脂秤报告和 JSON 备份导入。微信等消息推送尚未接入。

更新前导出备份，更新时保留原数据目录。详细使用说明随包提供，也可查看仓库 `docs/LOCAL_EDITION.md`。
