新增首次使用引导与帮助反馈入口。

- 新用户首次打开时显示两步引导，说明本地数据保存方式，设置称呼和常用模块。
- 提供创建任务、导入体脂秤报告、预览恢复 JSON 备份三个起点。
- 首页展示快捷入口与所选常用模块，右上角「?」可打开使用帮助和 GitHub 反馈页面。
- 反馈只预填软件版本与系统类型，由使用者检查后自行提交，不附带日志、健康数据或私人目录。
- 已有记录的升级用户不强制弹出引导；可在设置中重新打开。引导偏好保存在本地数据库，支持重启与多窗口修改保护。
- 升级测试验证旧版数据库的原有记录、称呼与迁移状态继续保留。

请选择系统对应的 Hygieia ZIP（Mac Intel / Apple 芯片或 Windows x64），不要下载 Source code 作为启动包。Mac 包目前未公证签名，第一次运行可能需要系统确认。

本版本不会自动跨设备同步。Apple 健康 / PulsHealth 自动连接尚未适配本地版；可先使用手动录入、体脂秤报告和 JSON 备份导入。微信等消息推送尚未接入。

更新前导出备份，更新时保留原数据目录。详细使用说明随包提供，也可查看仓库 `docs/LOCAL_EDITION.md`。
